# Top Jobs Per State

An interactive directory of the top employers across several U.S. states and Washington, D.C.

**Live site:** https://phoenixkey87-cmyk.github.io/Top-Jobs-Per-State/

## What's here

- `index.html` — Interactive, filterable table. Toggle between states, search by company or headquarters, and sort any column. Each state has its own color theme.
- Per-state PDFs for download/print:
  - Best Employers - Texas.pdf (Top 100)
  - Best Employers - Missouri.pdf (Top 75)
  - Best Employers - North Carolina.pdf (Top 100)
  - Best Employers - Tennessee.pdf (Top 80)
  - Best Employers - Georgia.pdf (Top 100)
  - Best Employers - Florida.pdf (Top 100)
  - Best Employers - Washington DC.pdf (Top 15)

## Regions covered

Texas, Missouri, North Carolina, Tennessee, Georgia, Florida, and Washington, D.C.

Each entry lists the employer's rank, name, year founded, and headquarters. A "Download PDF" button on the page links to the printable version for the currently selected region.

Data compiled from Best Employers by State rankings.
